Tekmora is the GitHub organisation for these tools: an agent runtime and a
community bot today, with more projects on their way here.

---

## Why Tekmora

Agents make claims fast: a test passes, a change is safe, a task is done. Each
Tekmora tool is built so that such a claim counts only with evidence behind it:
a command, a test or a measurement that anyone can run again.

### The name

From Greek *tekmor*: a set goal, and the sign that shows the way to it. Said
*TEK-mo-ra*.

## At a glance

| Repository | What it is |
| --- | --- |
| [**epitrop**](https://github.com/tekmora/epitrop) | Agent runtime and task-graph engine for the Tekmora ecosystem (Go); [documentation](https://tekmora.github.io/epitrop/). Name: Epitrop (eh-PEE-trop), from Greek *epitropos*, appointed trustee. |
| [**diallak**](https://github.com/tekmora/diallak) | Community bot for the Lusoris Discord hub that answers questions from the project documentation and cites its sources. Name: Diallak (dee-AHL-lak), from Greek *diallaktes*, the impartial mediator. |

More projects are moving here from their earlier home. Each arrives with its
first release under its new name.

## Contribute

- **Questions and ideas:** join the project Discussions in
  [epitrop](https://github.com/tekmora/epitrop/discussions) and
  [diallak](https://github.com/tekmora/diallak/discussions).
- **Security:** report vulnerabilities privately through each repository's
  security advisories ([epitrop](https://github.com/tekmora/epitrop/security/advisories/new),
  [diallak](https://github.com/tekmora/diallak/security/advisories/new)).
- **Code of conduct:** all community spaces follow the
  [Code of Conduct](https://github.com/tekmora/.github/blob/main/CODE_OF_CONDUCT.md).
